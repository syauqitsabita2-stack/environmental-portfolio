# 🌌 Cosmic Personal Portfolio

Website portofolio personal modern bertema luar angkasa dengan estetika dark mode kosmik, animasi partikel interaktif, dan aksen warna biru `#2c67ed`.

---

## ✨ Fitur & Komponen Utama

1. **Tema Kosmik & Latar Belakang Luar Angkasa Interaktif**:
   - Kanvas galaksi dengan bintang berkelap-kelip dinamis (*twinkling stars*).
   - Efek komet / *shooting stars* (meteor) yang meluncur melintasi angkasa secara berkala.
   - Efek nebula kosmik bercahaya (*ambient glow blur*).
   - Interaksi partikel gravitasi halus mengikuti pergerakan kursor mouse pengguna.

2. **Navbar Melayang (Floating Pill Navbar)**:
   - Terletak melayang di bagian tengah atas layar (`fixed top-5 left-1/2`).
   - Efek kaca tembus pandang (*frosted glassmorphism*) dengan *blue neon glow* (`#2c67ed`).
   - Indikator aktif berbasis animasi pegas (*Framer Motion layoutId*).
   - Menu drawer responsif untuk perangkat mobile / tablet.

3. **Halaman Utama (Hero Section)**:
   - Tampilan nama besar dengan teks gradien kosmik.
   - Efek mengetik mandiri dinamis (*Typewriter effect*) bergantian:
     - `'Junior Developer'`
     - `'Tech Enthusiast'`
     - `'Frontend Specialist'`
     - `'Full Stack Explorer'`
     - `'Creative Problem Solver'`
   - Visual miniatur planet & satelit luar angkasa dengan cincin orbit berotasi (React, Tailwind, Python, JS).
   - Tombol Call-to-Action interaktif dan baris tautan sosial media.

4. **Section About Me (Tentang Saya)**:
   - Kartu profil kosmik dengan ring rotasi neon dan status ketersediaan aktif.
   - Deskripsi filosofi koding dan dedikasi teknologi.
   - **Statistik Proyek Interaktif**:
     - *15+ Proyek Selesai*
     - *2+ Tahun Belajar & Coding*
     - *10+ Sertifikasi Kompetensi*
     - *99.9% Semangat Belajar*
   - **Riwayat Pendidikan**: Institusi, periode, IPK/predikat, dan fokus keahlian.
   - **Pengalaman Kerja & Proyek**: Riwayat organisasi, magang, dan freelance.

5. **Section Portfolio**:
   - Tab navigasi interaktif:
     - **Tab Projects**: Daftar proyek aplikasi web pilihan lengkap dengan gambar showcase, filter kategori, badge teknologi, modal detail, dan tautan live demo / GitHub.
     - **Tab Certificates**: Sertifikasi terakreditasi (Dicoding, Meta, FreeCodeCamp, BNSP) dengan ID kredensial, modal preview, dan tautan verifikasi.
     - **Tab Tech Stack**: Peta keahlian (Frontend, Backend, Tools & DevOps) dengan bar persentase penguasaan beranimasi.

6. **Section Kontak & Footer**:
   - Form transmisi pesan interaktif dengan validasi dan efek perayaan kosmik (*confetti animation*).
   - Kartu kontak langsung (Email dengan tombol salin otomatis, WhatsApp, Lokasi).
   - Tautan sosial media berbingkai glow.
   - Tombol *Back to Top* roket halus.

---

## 🛠️ Teknologi yang Digunakan

- **React 18** (Vite)
- **Tailwind CSS** (Custom cosmic colors & glows)
- **Framer Motion** (Animasi transisi, orbit rotasi, modal, & stagger)
- **Lucide React** (Ikonografi modern beresolusi tinggi)
- **Canvas Confetti** (Animasi selebrasi pengiriman pesan)

---

## 🚀 Menjalankan Proyek Secara Lokal

```bash
# Jalankan development server
npm run dev

# Buka pada browser
http://localhost:3000
```

Untuk memproduksi versi build siap rilis (deployment):
```bash
npm run build
```
